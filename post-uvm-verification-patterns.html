UVM Architecture, Factory Overrides & Scoreboard Patterns

Essential UVM architectural concepts every Design Verification engineer must master: phase execution order, objection mechanisms, Factory type/instance overrides, TLM analysis ports, and out-of-order scoreboards.

1. UVM Component Hierarchy & TLM Connectivity

A reusable UVM testbench cleanly separates stimulus generation from pin-level signaling and self-checking:

  • uvm_sequence_item & uvm_sequence: Transaction objects with rand fields and constraints; sequences generate streams of transactions inside body().
  • uvm_sequencer & uvm_driver: Connected via TLM seq_item_port ↔ seq_item_export. The driver pulls transactions using get_next_item(req), drives the virtual interface, and signals completion with item_done().
  • uvm_monitor: Passively samples virtual interface signals on clock edges, reconstructs transactions, and broadcasts them via uvm_analysis_port to subscribers (Scoreboard & Coverage collector).
  • uvm_scoreboard: Compares predicted reference-model outputs against actual DUT outputs using associative arrays (for out-of-order IDs) or per-source queues.

2. UVM Factory Overrides (Polymorphism in Action)

Registering components with `uvm_component_utils and objects with `uvm_object_utils enables runtime substitution without modifying environment code:

// Inside your UVM test's build_phase():
function void error_injection_test::build_phase(uvm_phase phase);
  super.build_phase(phase);
  // Global type override: swaps every base_axi_txn with err_axi_txn
  base_axi_txn::type_id::set_type_override(err_axi_txn::get_type());

  // Instance-specific override: only swaps agent[1]'s driver
  set_inst_override_by_type("env.axi_agt[1].drv",
                            axi_driver::get_type(),
                            err_axi_driver::get_type());
endfunction

3. Out-of-Order UVM Scoreboard Template

class ooo_scoreboard extends uvm_scoreboard;
  `uvm_component_utils(ooo_scoreboard)
  `uvm_analysis_imp_decl(_exp)
  `uvm_analysis_imp_decl(_act)

  uvm_analysis_imp_exp #(axi_txn, ooo_scoreboard) exp_imp;
  uvm_analysis_imp_act #(axi_txn, ooo_scoreboard) act_imp;

  axi_txn exp_pool[int unsigned]; // Indexed by unique transaction ID

  function void write_exp(axi_txn tr);
    exp_pool[tr.tid] = tr;
  endfunction

  function void write_act(axi_txn act);
    if (!exp_pool.exists(act.tid)) begin
      `uvm_error("SCB_UNEXP", $sformatf("Unexpected TID %0d from DUT", act.tid))
      return;
    end
    if (!act.compare(exp_pool[act.tid]))
      `uvm_error("SCB_MISMATCH", $sformatf("Data mismatch on TID %0d", act.tid))
    exp_pool.delete(act.tid);
  endfunction

  function void check_phase(uvm_phase phase);
    if (exp_pool.num() != 0)
      `uvm_error("SCB_DRAIN", $sformatf("%0d transactions left uncompleted!", exp_pool.num()))
  endfunction
endclass
