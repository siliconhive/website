SystemVerilog Constraints for Non-Overlapping Address Pair Generation

How to write bug-free SystemVerilog constraints for disjoint memory intervals—covering two-region pairs, N-region DMA descriptor tables, 4KB boundary guards, and solver skew avoidance.

▶ Run Live on EDA Playground (x/SR7f) ↗

Generating non-overlapping address ranges is one of the most common real-world verification requirements—and a favorite Design Verification interview question. Whether you are configuring DMA source/destination buffers, PCIe BAR windows, MMU page mappings, or dual-port SRAM partitions, overlapping regions can cause silent data corruption or bus deadlocks.

1. The Interval Disjointness Condition

Given two closed address intervals [start_a, end_a] and [start_b, end_b] where start_a <= end_a and start_b <= end_b, the two regions are strictly non-overlapping if and only if one interval finishes completely before the other begins:

Expressed as a single boolean constraint:

(end_a < start_b) || (end_b < start_a)

2. Pattern 1: Non-Overlapping Address Pair (Start + End or Start + Length)

Using bit [31:0] (or longint unsigned for 64-bit addresses) prevents signed-overflow wrap-around bugs during solver arithmetic:

non_overlapping_addr_pair.sv 
class addr_pair_txn;
  rand bit [31:0] start_a, end_a;
  rand bit [31:0] start_b, end_b;
  rand bit [15:0] len_a, len_b; // Byte length of each region

  constraint c_valid_ranges {
    // Bound address space and avoid 32-bit wrap-around overflow
    start_a <= 32'h000F_0000;
    start_b <= 32'h000F_0000;

    len_a inside {[16:4096]};
    len_b inside {[16:4096]};

    // Word-align start addresses
    start_a[1:0] == 2'b00;
    start_b[1:0] == 2'b00;

    // Inclusive end addresses
    end_a == start_a + len_a - 1;
    end_b == start_b + len_b - 1;
  }

  constraint c_non_overlapping {
    // Either Region A lies completely below Region B, or Region B lies below Region A
    (end_a < start_b) || (end_b < start_a);
  }

  function void display();
    $display("Region A: [0x%08h : 0x%08h] (%0d B) | Region B: [0x%08h : 0x%08h] (%0d B)",
             start_a, end_a, len_a, start_b, end_b, len_b);
  endfunction
endclass

3. Pattern 2: Scaling to N Non-Overlapping Address Pairs (Sorted Chain vs. Pairwise)

When an interviewer asks you to generalize from 2 regions to an array of N regions (start_addr[N], end_addr[N]), there are two ways to constrain them:

ApproachConstraint ComplexityPros & Cons
A. Pairwise Disjoint (i < j) O(N²) disjunctions Allows arbitrary ordering of regions in memory; solver runtime grows quadratically for large N.
B. Monotonically Sorted Chain O(N) linear inequalities Enforces end_addr[i-1] < start_addr[i]; solves dramatically faster for large descriptor tables (shuffle indices in post_randomize() if random order is needed).
n_non_overlapping_regions.sv 
class multi_region_cfg;
  rand int unsigned num_regions;
  rand bit [31:0]   start_addr[];
  rand bit [31:0]   end_addr[];
  rand bit [15:0]   size_bytes[];

  constraint c_num {
    num_regions inside {[4:8]};
    start_addr.size() == num_regions;
    end_addr.size()   == num_regions;
    size_bytes.size() == num_regions;
  }

  // O(N) Sorted Non-Overlapping Chain (Fast Solver Convergence)
  constraint c_disjoint_sorted {
    foreach (start_addr[i]) {
      size_bytes[i] inside {[64:2048]};
      start_addr[i][3:0] == 4'h0; // 16-byte aligned
      start_addr[i] <= 32'h00FF_0000;
      end_addr[i] == start_addr[i] + size_bytes[i] - 1;

      if (i > 0) {
        // Strictly non-overlapping: region i starts after region i-1 ends
        start_addr[i] > end_addr[i-1];
      }
    }
  }
endclass

4. Three Common Solver Traps in Address Range Constraints

Verification & Interview Gotchas
  1. 32-Bit Wrap-Around Overflow: If start_a = 32'hFFFF_FF00 and len_a = 512, start_a + len_a - 1 wraps around modulo 232 to 32'h0000_00FF, corrupting end_a < start_b. Always bound the maximum start address or compute bounds using 33-bit / 64-bit casts (64'(start_a) + len_a - 1).
  2. Off-by-One Boundary Collision: For byte-addressed memories, if Region A occupies [0x100 : 0x1FF] (256 bytes) and Region B starts at 0x1FF, they collide at byte 0x1FF. Always use strict inequality end_a < start_b (or start_a + len_a <= start_b).
  3. AXI 4KB Boundary Crossing: In AMBA AXI4 DMA tests, add (start_a[31:12] == end_a[31:12]) alongside non-overlapping constraints so a single burst never crosses a 4KB page boundary.
