1. Verilog RTL, Digital Design & DFT Basics

wire vs. reg vs. SV logic & RTL Gotchas

  • wire: Continuous assignment (assign) or module port connections; holds no state.
  • reg: Procedural assignment (always/initial); synthesizes to FF (clocked) or combinational/latch (unclocked).
  • logic (SV): Replaces both wire and reg for single-driver nets/variables (compile error on multi-driver → catches contention early; use wire for tri-state buses).
  • Why RTL outputs get stuck at XXXX: Missing/unasserted reset, uninitialized FFs, floating inputs, multi-driver bus contention, or casex/out-of-bounds indexing propagating X.

Edge Detector, Ring Counter & Clock Dividers

  • Dual-Edge Pulse Generator: Register a_d <= a; then pulse <= a ^ a_d; (1-cycle pulse on every 0→1 or 1→0 toggle).
  • N-Bit Ring Counter: One-hot circular shift register (4'b0001); reverts to initial state in N cycles (N × Tclk). Johnson Counter: Feeds ~q[N-1] to LSB; reverts in 2N cycles.
// Divide-by-2 & Divide-by-4 (50% duty cycle) + Dual-Edge Detector
always_ff @(posedge clk or negedge rst_n) begin
  if (!rst_n) begin cnt <= 2'b00; a_d <= 1'b0; pulse <= 1'b0; end
  else begin
    cnt <= cnt + 2'b01;   // cnt[0] = clk/2, cnt[1] = clk/4
    a_d <= a;
    pulse <= a ^ a_d;     // 1-cycle pulse whenever 'a' toggles
  end
end
DFT & Fault Testing Essentials: Stuck-at-0 (SA0) on node N requires controlling N=1 and sensitizing a path to an observable output. At-speed transition faults (slow-to-rise/fall) require a 2-vector launch-on-capture (LOC) or launch-on-shift (LOS) pattern running at functional clock frequency.

3. SV Event Regions, Tasks/Functions, Concurrency & SVA

Blocking (=) vs. NBA (<=) & Event Queue

  • Event Regions: Preponed (SVA sample) → Active (=, RHS of <=, $display) → Inactive (#0) → NBA (LHS of <=) → Observed (SVA eval) → Reactive (program) → Postponed ($strobe).
  • Trace Puzzle: a=1; b=5; b<=a+1; a<=10; c=a+b; d<=b+c;
    In Active: c = 1+5 = 6; RHS of d captures old b=5 → 5+6 = 11. In NBA: a=10, b=2, c=6, d=11.

Task vs. Function, fork & Semaphore

  • Timing inside Function: Illegal directly or in fork...join/join_any. Legal inside fork...join_none (spawns thread in 0 time).
  • Loop Trap: Always copy loop index into an automatic variable inside for loops before fork...join_none.
  • Isolated Watchdog: Wrap fork ... join_any disable fork; end join inside an outer fork...join so disable fork doesn't kill unrelated background threads.
  • Semaphore(1) + 2 Tasks (#10 each): Task 1 runs t=0..10, Task 2 runs t=10..20. Both complete by t=20 (well before #50).
  • uvm_event vs. SV event: SV event is a pulse (->ev; use wait(ev.triggered)); uvm_event (via uvm_event_pool::get_global()) carries a uvm_object payload and tracks trigger state.

Randomization & Constraint Patterns

  • rand vs. randc (cyclic without repeat).
  • dist {0 := 10, [1:5] :/ 20}; (:= per value; :/ split across range).
  • solve mode before len; • soft addr == 0; (overridable inline) • Ascending: arr[i] > arr[i-1] • randomize() returns 1/0 (no constraints → uniform across full bit width).
  • Matrix Constraints: Main diagonal i == j; Anti-diagonal i + j == N - 1; Upper triangle i <= j; Lower triangle i >= j.
  • Unique & Spacing: unique {arr}; and arr[i] - arr[j] >= 5.

Code vs. Functional Coverage & SVA

  • Code Coverage (Auto): Line, Branch, Condition, Toggle, FSM.
  • Functional Coverage (Manual): covergroup, coverpoint, bins, ignore_bins, illegal_bins, cross. Need both for sign-off.
  • SVA Implication: |-> (overlapping: same cycle) vs. |=> (non-overlapping: next cycle); ##[1:3] delay; $rose(), $past(), $stable(), throughout.
assert property (@(posedge clk) disable iff (!rst_n)
  $rose(req) |-> (req throughout (##[1:3] ack)));

4. Object-Oriented Programming (OOP) & Real-World Polymorphism

OOP Pillar Core Mechanism & SystemVerilog Syntax Real-World & Verification Application
Encapsulation Bundles data & methods in a class; access controlled via public (all), protected (self + child), local (self only). Real World: Car dashboard exposes steering/pedals while hiding ECU fuel-injection internals.
DV: Packet hides internal CRC state while exposing pack().
Inheritance class Child extends Parent; reuses base fields, methods & constraints; calls super.new(). Real World: ElectricCar & Truck inherit wheels/brakes from Vehicle.
DV: AxiErrorTx extends AxiBaseTx to add error injection.
Polymorphism Base handle points to derived object; virtual method dispatches child implementation at runtime ($cast to downcast). Real World: Universal payment gateway calls pay() on CreditCard, UPI, or ApplePay objects identically.
DV: UVM Factory swaps base_tx with err_tx; Driver calls req.pack() without knowing the subtype.
Abstraction virtual class cannot be instantiated directly; pure virtual methods enforce a mandatory interface contract. Real World: Power outlet standard defines voltage/pin shape without specifying what appliance plugs in.
DV: uvm_driver / abstract scoreboard predictor templates.

5. UVM Architecture, Phases, Factory & Sequences

UVM Execution Phases (Strict Order)

  1. build_phase (Top-Down, Func): Create children via Factory; fetch uvm_config_db.
  2. connect_phase (Bottom-Up, Func): Connect TLM ports/exports (Driver ↔ Sequencer, Monitor → Scoreboard).
  3. end_of_elaboration_phase (Bottom-Up, Func): Topology check (print_topology()).
  4. start_of_simulation_phase (Bottom-Up, Func): Pre-run banners.
  5. run_phase (Parallel, Task — Time-Consuming): Main stimulus/checking; runs alongside 12 sub-phases (reset, configure, main, shutdown × pre/main/post). Controlled by raise_objection / drop_objection.
  6. extract → check → report → final (Bottom-Up, Func): Collect coverage, check empty queues, print pass/fail summary.

Factory, Config DB, Sequence Handshake & Verif Plan

  • Component vs. Object & TLM: Components have hierarchy & phases; Objects are transient. TLM port initiates, export forwards, imp implements. copy() copies into existing object; clone() creates new + copies.
  • Factory Overrides & Callbacks: Global set_type_override_by_type vs. scoped set_inst_override_by_type; uvm_callback stacks multiple hooks dynamically during run_phase without subclassing.
  • Sequence ↔ Driver Handshake: Sequence calls start_item(req) → randomizes → finish_item(req); Driver calls get_next_item(req) → drives pins → item_done().
  • Multi-Sequence Unique TIDs: Use a static int next_id counter inside the transaction class (incremented atomically in post_randomize()) so parallel sequences never collide.
  • 8-Bit Shift Register Verif Plan: (1) Features: reset, parallel load priority, left/right shift, hold; (2) Stimulus: walking-1s/0s, reset-on-the-fly, random control; (3) Checkers: cycle-accurate predictor + SVA hold check; (4) Closure: 100% bit toggle + mode cross coverage.

6. Bus Protocols, Cache Coherency & Pipeline Architecture

Protocol Handshake & Architecture Critical Verification Checks
AMBA APB Non-pipelined 2-phase bus: SETUP (PSEL=1, PENABLE=0) → ACCESS (PSEL=1, PENABLE=1), stalls while PREADY=0. PADDR, PWRITE, PWDATA stay stable during wait states; verify PSLVERR handling & zero-wait vs. multi-wait transfers.
AMBA AXI4 5 decoupled channels (AW, W, B, AR, R) using VALID/READY; out-of-order completion via ID tags; bursts up to 256 beats. VALID must never wait for READY; payload stable until handshake; WLAST on final beat; no 4KB boundary crossing.
SPI / I2C SPI: 4-wire full-duplex (4 CPOL/CPHA modes).
I2C: 2-wire open-drain (SDA, SCL), ACK/NACK.		 SPI: Sample/launch edge alignment.
I2C: START/STOP (SDA toggles while SCL=1), clock stretching, arbitration.

Pipeline Hazards & MIPS Cycle Formula

  • 3 Hazard Types: Structural (hardware resource conflict), Data (RAW, WAR, WAW), Control (branch/jump flush).
  • Ideal Pipeline (K stages, N instrs): Cycles = K + (N − 1) (7 instrs, 4 stages = 10 cycles).
  • RAW WITH Forwarding: ALU-to-ALU bypasses from EX to EX → 0 stalls (10 cycles; 1 stall only for Load-Use).
  • RAW WITHOUT Forwarding: Stalls in ID until WB → 2 stall bubbles per back-to-back RAW pair (10 + 6×2 = 22 cycles).

Cache Policies, MESI & CLI Overrides

  • Write-Through vs. Write-Back: Write-Through updates cache + RAM simultaneously (simple, higher bus traffic). Write-Back updates cache only and sets a dirty bit, writing to RAM only on eviction (faster, lower bandwidth, requires coherency).
  • MESI States: Modified (dirty, exclusive), Exclusive (clean, only copy), Shared (clean, multiple caches), Invalid.
  • SV CLI Parameter Override:
    VCS: -pvalue+tb_top.WIDTH=32
    Questa: -gWIDTH=32 • Xcelium: -defparam tb_top.WIDTH=32

7. Data Structures, Coding Patterns, Python & Linux

Data Structures & Bit/Array Coding

  • Array Access: O(1) via base + index × elem_size.
  • Reverse Singly Linked List (O(N) time, O(1) space): Save nxt=curr.next, set curr.next=prev, advance prev=curr, curr=nxt.
  • Shortest Path in Grid/Maze: Use BFS (queue) for unweighted O(R × C) shortest path.
// Pack all 1s in a 32-bit number to MSB (e.g. 0x00E1_0F00 -> 0xFF00_0000)
function automatic bit [31:0] move_ones_msb(bit [31:0] a);
  int ones = $countones(a);
  return (ones == 0) ? 32'h0 : (32'hFFFF_FFFF << (32 - ones));
endfunction

Python Log Filter & Linux One-Liners

# Run commands from file & save ERROR/FAILURE lines to output file
import subprocess, re
with open("cmds.txt") as f, open("errors.log", "w") as out:
    for cmd in filter(None, map(str.strip, f)):
        res = subprocess.run(cmd, shell=True, capture_output=True, text=True)
        for line in (res.stdout + res.stderr).splitlines():
            if re.search(r"(ERROR|FAILURE)", line):
                out.write(f"[{cmd}] {line}
")
